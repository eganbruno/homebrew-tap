# homebrew-tap

Homebrew formulae for [eganbruno](https://github.com/eganbruno)'s tools.

```bash
brew install eganbruno/tap/grit
```

Formulae in this repository are generated by
[dist](https://github.com/axodotdev/cargo-dist) when a release is tagged in the
source repository. Do not edit them by hand — changes will be overwritten by
the next release.

| formula | source |
| --- | --- |
| `grit` | [eganbruno/grit](https://github.com/eganbruno/grit) — work across many git repositories from anywhere, by alias |
